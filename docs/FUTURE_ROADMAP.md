## 開発ワークフローの改善案

### KAMUI-4D タスク設計のコツ（今回の学び）

- 独立性の高いタスクに分割する（サービス層は並列に向く、ページ + ストアの接続は逐次に向く）
- 各タスクにインターフェース定義（types）を事前に渡す → 整合性エラーが減る
- 修正指示は具体的なファイルパス + コード例を含める（抽象的な指示は反映されにくい）

### Claude Code 自律タスクのコツ

- 1タスクの粒度は「1コミットで完結する単位」が最適
- 依存関係のあるタスクは実行順序を明示する
- テスト付きタスクは「実装 + テスト」をセットにする
