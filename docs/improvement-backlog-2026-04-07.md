# Improvement Backlog

更新日: 2026-04-07

## P0 今日のテストで見えた問題

### 1. 吹き出し配置が不自然
- 上の横吹き出しと下の縦吹き出しが同居して不自然になるケースがある
- 現在は `top` など固定寄りで配置しており、人物位置や読み順を見ていない

### 2. セリフ反映が弱い
- セリフは吹き出しには入るようになったが、画像生成の感情反映がまだ弱い
- `感情 / 表情 / 口元 / 視線` への明示マッピングが必要

### 3. 画像に内側余白が出る
- モデル側が疑似フレームや白フチを描くケースがある
- `full-bleed` 指示は入れたが、まだ十分ではない

## P1 すぐ着手する改善

### A. 吹き出し配置ルールエンジン
- 1コマ1吹き出しの基本配置を `右上優先` に統一
- `日本語 / 右→左` 用の読み順ルールを実装
- 顔位置推定がない場合でも `重要被写体中央回避` の簡易ルールを入れる
- モノローグは `しっぽなし矩形` に分岐

### B. ネーム項目の拡張
- 各コマに以下を追加
  - `emotion`
  - `shotType`
  - `compositionNote`
  - `dialogueType`
- 画像生成前の土台として利用

### C. ラフネーム段階
- いきなり本生成せず、まず `ラフネーム` を作る導線を追加
- MVP:
  - ページテンプレ
  - コマごとのテキスト
  - 簡易グレーボックス / サムネイル
