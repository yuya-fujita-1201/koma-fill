# Manga Knowledge Base

`koma-fill` を「画像生成ツール」から「漫画制作ツール」へ寄せるための実務知識メモ。

更新日: 2026-04-07

## 1. コマ割りの基本原則

### 1-1. 単調さと大ゴマの緩急を作る
- 均一なコマが続くと読みやすい反面、続くと飽きやすい。
- その単調さの後に大ゴマや見せゴマを置くと、めくりや感情の強調が効く。
- `koma-fill` では「全部のコマを均等に強くする」のではなく、テンプレごとに `見せゴマ` と `つなぎゴマ` の役割を持たせるべき。

### 1-2. ページ全体で視線を設計する
- 漫画はコマ単体ではなく、ページ全体の読み順と視線誘導で読みやすさが決まる。
- 日本式右→左なら、ページ全体の視線は逆Zに近い流れを崩さない方が読みやすい。
- `koma-fill` では、テンプレごとに「読む順」「視線の落とし先」「最終コマの重み」を定義する。

### 1-3. ネームは先に役割を決める
- 画像をいきなり出すより、先に各コマの役割を決める方が品質が安定する。
- 必要な最低項目:
  - 出来事
  - セリフ
  - 感情
  - カット距離
  - 構図メモ

## 2. 吹き出しの基本原則

### 2-1. 誰のセリフか一瞬で分かることが最優先
- 吹き出しのしっぽは発言者の口元方向に向ける。
- しっぽがずれると「誰のセリフか」が曖昧になる。
- 人物同士で吹き出しがクロスすると混乱が起きやすい。

### 2-2. 視線誘導を壊さない
- 吹き出しはコマ内でも読み順に沿って並ぶ方が自然。
- 日本語漫画なら、通常は `右上 -> 左下` に流れる配置の方が読みやすい。
- 同じコマに複数吹き出しを置く場合、上から下だけでなく `右から左` も守る。

### 2-3. 長文は1つに詰め込まない
- 長文は文節単位で改行、必要なら吹き出し自体を分ける。
- 大きい1つの吹き出しに長文を押し込むと、余白も密度も不自然になりやすい。
- `koma-fill` の自動レイアウトでも、文字数ベースで `1吹き出し / 2吹き出し` を切り替えるべき。

### 2-4. コマの主役を隠さない
- 吹き出しはまず空間の余白、次に背景、最後に人物へ重ねる。
- 顔・手・視線先・重要小道具の上に吹き出しを置くと演出が死にやすい。
- まず「禁止領域」を決め、その外で配置候補を探す方が実装しやすい。

### 2-5. 吹き出しの形は感情の補助記号
- 通常会話: 丸み吹き出し
- モノローグ/説明: 四角 or 角丸弱め
- 強い感情/叫び: トゲ or 強い輪郭
- 思考: 雲型やしっぽ弱め
- `koma-fill` では、ネームの `セリフ種別` を追加すると自動選択しやすい。

## 3. 実装へ落とすときのルール

### 3-1. 吹き出し自動配置の推奨手順
1. パネル内の基本アンカーを複数用意する
   - 右上
   - 左上
   - 中上
   - 右中
   - 左中
   - 下寄り
2. 読み順に従って優先アンカーを決める
3. 顔・主要被写体・既存吹き出しと衝突しない候補を選ぶ
4. 文字数で高さを可変にする
5. しっぽは発言者の頭部中心ではなく `口元寄り` に向ける

### 3-2. 自動配置のMVPルール
- 1コマ1吹き出し:
  - まず `右上`
  - ダメなら `左上`
  - ダメなら `中上`
- 1コマ2吹き出し:
  - `右上` と `左上`
  - もしくは `右上` と `右中`
- モノローグ:
  - しっぽなし
  - コマ上部の横長ボックス

### 3-3. 画像生成プロンプトとの分離
- セリフ本文を画像自体に焼き込ませるより、まずは `感情 / 口形 / 間` の指示として使う。
- 吹き出し文字はレイアウト合成で後載せする方が再現性が高い。
- 例:
  - セリフ: 「これは……美しい？」
  - 画像生成側: 驚きと戸惑いの混ざった静かな表情
  - レイアウト側: 吹き出しとして文字を載せる

## 4. ネーム工程の推奨フロー

1. ストーリー入力
2. ページテンプレ選択
3. ネーム作成
   - 手動入力が主
   - AI は叩き台作成
4. ネーム編集
   - 出来事
   - セリフ
   - 感情
   - カット距離
   - 構図メモ
5. ラフプレビュー
   - 文字＋簡易サムネイル
   - 必要ならラフ画像生成
6. 本生成
7. コマ単位の差し替え

## 5. `koma-fill` への示唆

### 優先度 高
- 手動ネームを主導線にする
- 吹き出しを panel `speechBubbleText` から自動反映する
- 吹き出し位置を右上固定ではなく、読み順と顔位置に応じて選ぶ
- コマごとに `感情 / カット / 構図メモ` を持てるようにする

### 優先度 中
- ラフネーム画像を生成する中間工程
- 吹き出しの複数分割
- 台詞量による吹き出しサイズ可変
- モノローグと会話の形状分岐

### 優先度 低
- 見開き演出
- フキダシの手動ドラッグ微調整
- 効果線や描き文字の自動提案
